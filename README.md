# 🧙‍♂️ Cyber Wizard

> **The Ultimate Computer Fundamentals & Technician Toolkit Web Application**

Cyber Wizard is an interactive web platform designed for computer technicians, IT students, system administrators, and technology enthusiasts. It provides essential computer hardware & operating system fundamentals, a curated software download hub with direct vendor links, a CLI command cheatsheet with one-click copy, an interactive diagnostic troubleshooter, and a tech knowledge self-assessment quiz.

---

## ✨ Features

- 💻 **Computer Fundamentals**: In-depth architecture guides covering CPU, RAM, Storage (SSD/NVMe vs HDD), Motherboards, File Systems (NTFS vs FAT32 vs ext4), Boot Modes (MBR vs GPT / UEFI), Networking (IP, Subnetting, DNS, DHCP), and Maintenance (3-2-1 Backup Rule).
- 📦 **Software Download Hub**: Verified, direct official download links for top diagnostic tools (*HWiNFO, CPU-Z, CrystalDiskInfo*), IT utilities (*Wireshark, PuTTY, AnyDesk*), drive archivers (*Rufus, 7-Zip*), and developer apps (*VS Code, VLC*).
- 💻 **Technician CLI Cheatsheet**: Essential Windows (CMD & PowerShell) and Linux terminal commands (`ipconfig /all`, `sfc /scannow`, `chkdsk`, `tracert`, `netstat`, `lsblk`, `htop`) with instant **Copy to Clipboard**.
- 🩺 **Tech Diagnostic Wizard**: Step-by-step troubleshooter to diagnose common hardware & OS issues like *No Display / Black Screen*, *BSOD Crashes*, *CPU Overheating*, and *Network Disconnections*.
- 🧠 **Interactive Tech Quiz**: Self-assessment quiz with real-time scoring, progress tracking, and detailed technical explanations.
- ⚡ **Futuristic Cyber Aesthetic**: Built with neon cyan/purple glow theme, glassmorphism UI elements, dark mode optimization, and micro-interactions.

## 🚀 Quick Start (Local Development)

1. **Clone Repository**:
   ```bash
   git clone https://github.com/vishn2015stp/cyberwizard.git
   cd cyberwizard
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Run Development Server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

4. **Build Production Bundle**:
   ```bash
   npm run build
   ```
